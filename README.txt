# SkillBridge AI — SIH26044 Prototype

Open `index.html` in Chrome/Edge.

Demo flow for judges:
1. Dashboard — show Career Readiness Score and recommended opportunity.
2. Skill Assessment — submit the sample assessment.
3. Skill DNA — show verified skills and gaps.
4. Learning Roadmap — show personalized upskilling path.
5. Opportunities — show 92% compatibility and explain WHY it matches.
6. Application Tracker — show application + mentor feedback loop.

This is an interactive frontend prototype for the internal hackathon. It is intentionally demo-focused and does not require a backend.
